# 幻域无双 · Realm Rampage

3D 奇幻风的「无双割草 × 肉鸽随机技能」网页游戏。手动连招、蓄力技、闪避与无双乱舞，一次斩落成百上千的亡骨大军；每次升级三选一随机技能，按 DOTA2 饰品式 8 档稀有度分色，10 大派系叠加觉醒，跨派系羁绊与三派系组合自由搭配；战地商店支持 DOTA2 式装备合成与神器升级。

- **公网试玩**：<https://wildwoodguardiansgame.cpolar.cn/>（本机通过 cpolar 映射，电脑开机且服务运行时可访问）
- **源码**：<https://github.com/Tenet-zjx/realm-rampage>

## 玩法

| 系统 | 内容 |
|---|---|
| 战斗 | WASD 移动；J/左键普攻（最多 5 段）；在第 n 段后按 K/右键打出蓄力技 C(n+1)，共 C1–C6；空格闪避（无敌帧）；L 无双乱舞，生命低于 25% 时为真·无双 |
| 英雄 | 圣誓骑士、狂战士、星辉法师、影刃游侠、暗夜刺客（金币解锁）、亡骨术士（金币解锁）。每人有专属连招、蓄力技、无双、3 张专属技能卡、3 款皮肤、10 级熟练度 |
| 技能 | 10 派系 × 10 技能、30 通用被动、25 进化至宝形态、18 英雄专属，共 173 张技能卡；主动技 4 槽（U I O P / Q E R F），自动技 6 个，被动 8 个 |
| 稀有度 | 普通、罕见、稀有、神话、传奇（紫）、远古、不朽、至宝，卡面始终同时显示文字 |
| 搭配 | 同派系 2/4/6/8 个技能逐级激活加成（8 个为派系觉醒）；20 个双派系羁绊；6 个三派系组合大招；满级技能 + 指定被动进化 |
| 模式 | 冒险闯关（6 章分支路线图：战斗、精英、商人、奇遇、篝火、宝藏、首领；第 6 章为隐藏章节）、无尽模式（每 5 波首领、每 10 波变异）、每日试炼（固定种子与英雄，10 分钟，2 个词缀） |
| 难度 | 简单割草、适中、困难、地狱（精英带 2–3 个词缀，首领多一阶段，不可复活） |
| 关卡目标 | 歼灭、斩将、攻占据点、守护水晶、突围、坚守、精英讨伐、首领战 |
| 敌人 | 33 种敌人（KayKit 骷髅、Blender 改造变体、Blender 原创怪物），其中 15 种特殊敌人会施加负面状态；10 种精英词缀、敌将、8 位首领（含双子将军）。所有范围攻击都有与真实判定一致的地面预警 |
| 负面状态 | 19 种：蛛网（叠满被缚）、剧毒（降低治疗）、恐惧、噬魂链接（吸取无双）、冻伤（叠满冰冻）、妖术变蛙、沉默、钩锁拖拽、石化凝视、迷乱（方向颠倒）、腐蚀、定时炸弹（爆炸瞬间闪避可规避）、时间迟滞、流血（移动时加剧）、致盲（普攻可能落空），以及减速、冰冻、缠绕、灼烧。控制类状态可被免控效果抵挡、被无双挣脱，圣水可全部净化；状态栏显示层数与剩余时间，并配有全屏效果 |
| 画面 | 每个章节有独立的程序化地面（鹅卵石或大理石，带法线起伏；熔火与深渊有发光裂缝）、随风摆动的草丛与地面散布物、遮挡英雄的道具自动透明、分章节调色、敌人破土尘土与尸体痕迹；所有技能与物品图标为矢量图案 |
| 战地商店 | 30 配件、33 合成装备 + 12 件神器（2–4 层合成树，一键补齐、自动合成、出售返还 50%），16 种消耗品，6 格装备 + 药品栏，主动装备 Z/X/C |
| 掉落 | 40 件中立秘宝（5 阶）、8 种地图神符、敌将宝箱 |
| 局外养成 | 账号等级（提升基础属性、获得天赋点）、40 节点天赋盘、金币商城 20 种强力道具（出征最多带 3 件）、英雄解锁与熟练度、图鉴、50 个成就与称号 |
| 打击反馈 | 顿帧、震屏、FOV 冲击、受击闪白、击退挑空与空中追击、溶解死亡、WebGL 伤害数字、KO 计数、连击、多杀播报、敌将击破横幅 |

其他按键：B 商店 · Esc 暂停 · 6–9 药品 · 升级时 1–4 选卡、R 重抽。手机横屏使用虚拟摇杆与按键簇。

## 本地运行

```bash
npm ci
npm run dev
```

开发服务器地址 http://127.0.0.1:5190 。也可以双击 `启动试玩.command`。

```bash
npm test
```

## 公网试玩（cpolar）

```bash
./scripts/public-preview.sh start
```

`start` 会构建（若无 `dist/`）、安装两个 LaunchAgent（`vite preview` :4180 与 cpolar 隧道），并接管保留子域名 `wildwoodguardiansgame`。其他子命令：`status`、`update`（重新构建，立即改变公网内容）、`stop`、`restore-wildwood`（把子域名交还给森野守卫）。也可双击 `启动公网试玩.command` / `停止公网试玩.command`。

## 技术

- Three.js 0.186 + Vite 7，纯 ES Modules，无框架。
- 模拟层（`src/game/`）不依赖 THREE/DOM，种子随机可复现；表现层读取每帧的 `game.events` 与 `game.effects`。
- 杂兵使用「骨骼动画烘焙到纹理 + InstancedMesh 着色器蒙皮」，数百个独立动画单位同屏。
- 技能特效由地面贴花、GPU 粒子、能量网格、锯齿闪电与闪光灯组合，每个派系有独立的形状、颜色和节奏。
- 音效与音乐全部由 WebAudio 实时合成。
- 模型管线：`npm run assets:fetch` 下载锁定版本的 KayKit CC0 源文件，`npm run models:build` 用 Blender 无界面重建全部模型（动画合并、改色、加部件、原创怪物与 Boss）。

## 验证记录（v1.1.0 · 2026-10-26）

- `npm test`：32 项测试全部通过（新增 7 项负面状态测试：叠层转化、免控与无双挣脱、圣水净化、定时炸弹闪避规避、迷乱反向、石化凝视、噬魂链接、钩锁与恐惧）。
- `npm run test:ui`：构建通过，4 项 Playwright 端到端测试通过（标题页、图鉴 42 个敌人及 15 个负面状态标签、特殊敌人施加状态并在状态栏显示、定时炸弹倒计时与引爆），控制台无报错。
- 平衡（`node scripts/balance.mjs`，脚本 Bot 绕圈攻击、会闪避即将结算的预警，但不会回防，零养成）：
  - 第 1 章四档难度两名英雄均通关（地狱最低生命 73%）。
  - 第 3 章简单到困难均通关；地狱狂战士通关（最低 10%），骑士在第一关约 20 秒内阵亡。
  - 第 5 章简单、适中均通关；困难狂战士通关（最低 1%），骑士在第一关阵亡；地狱两人开局即败（零养成下的设计预期）。
  - 同一种子去掉 15 种特殊敌人后，骑士在第 5 章困难和第 3 章地狱同样失败，说明这两次失败来自骑士的基础强度，而非新敌人。
- 性能：`npm run bench`（无头 Chrome，ANGLE/Metal，383 个动画敌人 + 6 个满级自动技能）平均 14.1 ms/帧，p95 31 ms。同一天在同一台机器上测 v1.0.0 提交为 13.9 ms / p95 31 ms，新画面没有带来可测的性能退化；v1.0.0 记录的 8.2 ms 是另一天的测量结果。数据见 `docs/verification/benchmark.json`。
- 画面：在 1400×820 与 844×390 视口截图检查了 15 种特殊敌人的技能、负面状态栏与全屏效果、图鉴、六个章节地面。
- **尚未验证**：真实手机与平板、Windows/Android 浏览器、新增音效的实际听感（无头浏览器无法试听），以及真人玩家对负面状态强度的长期体验。
