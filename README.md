# 幻域无双 · Realm Rampage

3D 奇幻风的「无双割草 × 肉鸽随机技能」网页游戏。手动连招、蓄力技、闪避与无双乱舞，一次斩落成百上千的亡骨大军；每次升级三选一随机技能，按 DOTA2 饰品式 8 档稀有度分色，10 大派系叠加觉醒，跨派系羁绊自由搭配。

> 开发中。下方“版本记录”只写实际完成并验证过的内容。

## 玩法一览（规划）
- **模式**：冒险闯关（6 章分支路线图）、无尽模式、每日试炼
- **难度**：简单割草 / 适中 / 困难 / 地狱
- **技能**：10 派系 × 10 技能 + 通用被动 + 英雄专属 + 进化至宝形态，约 173 张技能卡
- **稀有度**：普通、罕见、稀有、神话、传奇、远古、不朽、至宝
- **系统**：DOTA2 式战地商店与装备合成、中立秘宝、地图神符、金币商城强力道具、账号等级与天赋盘、英雄熟练度、图鉴与成就

## 本地运行
```bash
npm ci
npm run dev          # http://127.0.0.1:5190
npm test             # 逻辑测试
```

## 技术
Three.js + Vite，纯 ES Modules。模拟层与渲染层分离、种子随机可复现；杂兵使用骨骼动画烘焙纹理 + InstancedMesh 实现数百单位同屏。

## 素材
角色与场景模型源自 KayKit（CC0），经 Blender 二次加工，详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
